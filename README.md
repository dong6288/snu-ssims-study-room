# SNU Study Room

서울대 공대생이 Chrome의 **예약하샤**에서 스터디룸을 찾고 예약할 수 있는 Codex 스킬입니다. 본인이 쓰는 Chrome 프로필로 접속하며, 예약을 요청하면 확인된 조건에 맞는 무료 신청 한 건을 제출합니다. [예약하샤](https://ssims.snu.ac.kr/index.do) · [서울대 정보화본부 안내](https://ist.snu.ac.kr/%EA%B3%B5%EA%B0%84%EA%B4%80%EB%A6%AC%EC%98%88%EC%95%BD%ED%95%98%EC%83%A4/)

**빈 시간 조회**는 Chrome 연결과 스킬 설치만 하면 됩니다. **무료 예약 신청**까지 맡기려면 Node.js 24 이상과 같은 PC의 신청 기록이 필요합니다.

## Windows 설치

1. [GitHub 소스 ZIP](https://github.com/dong6288/snu-ssims-study-room/archive/refs/heads/main.zip)을 받아 압축을 풉니다.
2. 압축을 푼 폴더의 PowerShell에서 `.\Install-SnuStudyRoom.ps1`을 실행합니다. 설치 경로가 출력됩니다. 서명 또는 실행 정책 오류가 뜨면 Codex의 `$skill-installer` 경로를 사용합니다.
3. ChatGPT 데스크톱의 **Codex 채팅**을 새로 열고, 공식 확장이 연결된 실제 `@Chrome`을 선택합니다. [Chrome 연결 안내](https://learn.chatgpt.com/docs/chrome-extension)
4. 예약 신청까지 맡기려면 Node.js 24 이상에서 [신청 기록을 초기화](docs/INSTALL.md#무료-예약-신청-준비)합니다. 조회만 할 때는 Node 설치와 초기화가 필요 없습니다.

Codex의 `$skill-installer`로 설치할 때는 `dong6288/snu-ssims-study-room` 저장소의 `skills/snu-ssims-study-room`을 지정하세요. [세부 설치법과 검증](docs/INSTALL.md)

이미 설치했다면 [Windows 업데이트 안내](docs/INSTALL.md#windows에서-업데이트)를 따르세요.

## 사용 예시

```text
@Chrome $snu-ssims-study-room 금요일 16~18시 관악 전체에서 4명 스터디룸을 찾아줘. 모니터는 필수야. 검색만 해줘.
```

```text
@Chrome $snu-ssims-study-room 다음 주 화요일 오후 2~4시, 4명이 팀 발표 연습할 무료 스터디룸 한 곳을 신청해줘. 43-2동을 선호해.
```

건물을 지정하지 않으면 해당 캠퍼스의 결과를 끝까지 읽습니다. 캠퍼스를 생략하면 관악을 검색하고, `전체 캠퍼스`라고 하면 현재 계정에 표시되는 캠퍼스 탭을 순회합니다. 공간 이름, 대관 목적, 이용 자격, 운영시간, 인원과 장비를 확인합니다. 검색에 나온 공간이나 비어 보이는 달력 칸만으로 예약 가능이라고 판단하지 않습니다. [Chrome 작업 흐름](skills/snu-ssims-study-room/references/ssims.md)

날짜와 시간만 정해 예약을 맡기면 관악의 적합한 무료 공간을 고릅니다. 신청 인원 선택을 맡겼고 시설과 양식이 허용하면 신청자 1명만 등록합니다. 함께 이용할 인원을 알려주면 방의 정원과 시설 이용 조건을 확인하는 데 사용합니다. 양식이 실제 이용 인원을 요구할 때는 해당 인원을 입력합니다. 사용목적은 용도에 가까운 선택지를 고르고, 제목과 내용은 `스터디룸 이용`처럼 간단히 적습니다.

이 스킬에서 `예약해줘` 또는 `신청해줘`라는 요청은 신청자 본인이 `개인정보 수집 및 이용동의`와 `공간 사용 안내사항`을 알고 동의하며, 두 항목의 체크와 해당 예약의 제출까지 맡긴다는 의미입니다. 스킬은 공식 화면에서 두 항목과 적용 범위를 확인하고 체크한 뒤, 완성된 신청서를 간단히 안내하고 한 건을 바로 제출합니다. 같은 동의나 제출 승인을 다시 묻는 단계는 없습니다. 검색이나 신청서 준비만 요청한 경우에는 그 범위까지만 진행합니다.

인원은 숫자 선택으로 먼저 입력하고 화면의 `총 인원수`를 확인합니다. 로그인, 개별 참가자 등록·인증, 다른 참가자의 개인정보 동의 등 공식 화면에서 개인 조작을 요구하는 부분은 직접 처리합니다. 새 동의 항목, 기존과 실질적으로 달라진 조건, 동의 거부·철회가 있으면 해당 부분을 확인합니다. Codex의 도구 실행 자동 검토나 브라우저가 별도 승인을 요구하면 실제 차단 사유를 안내합니다.

접수 또는 승인 대기 상태라면 방문 전에 예약하샤의 `나의예약현황`에서 확정 여부를 확인하세요. 인터넷이 끊기는 등 결과가 불분명하면 같은 시간대 신청을 보류하고 공식 내역부터 확인합니다. 유료 공간의 신청과 결제, 중앙도서관 시설예약은 각각 공식 화면과 [중앙도서관 앱](https://lib.snu.ac.kr/about/mobile/mobile-pass/)으로 안내합니다.

`11월 25일 14:30–16:30 43-2동 104호 예약 취소해줘`라고 하면 본인의 `나의예약현황`에서 일치하는 한 건을 찾고 공식 취소 결과를 확인합니다. 같은 시간에 후보가 여러 건 있거나 비용·환불 조건이 있으면 해당 부분만 확인합니다. [취소 절차](skills/snu-ssims-study-room/references/ssims.md#5-cancel-one-booking)

스킬이 메뉴에 보이지 않으면 새 Codex 채팅을 열어 보세요. `@Chrome`이 보이지 않으면 [공식 연결 안내](https://learn.chatgpt.com/docs/chrome-extension)에 따라 Chrome 확장을 확인하세요.

## 검증

로컬 시험은 로컬 기록의 상태 전이와 중복 신청 방지를 확인합니다. Chrome 모의 시험은 별도 임시 Chrome 프로필과 가상 화면에서 로그인, 두 페이지 조회, 내용 확인, 신청 1회, 모의 확정과 응답 지연 뒤 재신청 보류를 재현합니다. 서울대 실서비스에서는 읽기 전용으로 검색과 신청서 열기를 확인했습니다. 실제 예약 제출과 서버의 확정 처리는 모의 시험 범위 밖입니다. [재현 명령](docs/INSTALL.md#모의-시험) · [데이터 처리](PRIVACY.md)
